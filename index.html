⚡ Host Your Own Schedula on GitHub Pages (github.io)

This application is pre-loaded with your Offered Course Report-2.xlsx and ALSO supports automatic Excel loading from data/Offered_Course_Report.xlsx or via the Load Excel button.

  1. Create a new public repository on GitHub named schedula.
  2. Upload index.html (and optionally data/Offered_Course_Report.xlsx) from the provided ZIP package.
  3. Go to Settings → Pages in your GitHub repository.
  4. Under Build and deployment, select Deploy from a branch → main → / (root) and click Save.
  5. In ~60 seconds, your site will be live at https://<your-username>.github.io/schedula/!
  6. Whenever a new semester's Excel file comes out, either replace data/Offered_Course_Report.xlsx in your repo OR click Load Excel in the top bar!
